## 0. 요청 요약

## 2. 목표 호출 구조와 예상 호출 횟수 (구현 전 추정)

### 2-1. 무료 면접 (3문항)

| 단계 | AI 호출 | 내용 |
|---|---|---|
| 준비 | 0 | 채용공고 핵심(주요업무·자격요건·우대사항)과 이력서 핵심 문장은 브라우저에서 규칙 기반으로 추출 |
| Q1 | 0 | 직무·경력에 맞춰 **사전 생성 질문 은행**에서 선택 |
| 답변1 → Q2 | 1 | 답변1 요약 + JD 핵심 + 이력서 사실 3~5개로 다음 질문 생성(채점 공개 안 함) |
| 답변2 → Q3 | 1 | 동일 |
| 답변3 → 결과 | 1 | **요약 평가 1회**(전체 점수 1개, 강점 1, 고칠 점 1) |
| **합계** | **3회** | 이미지 업로드 시 장당 +1 |

### 2-2. 유료 실전 면접 (11문항)

| 단계 | AI 호출 | 내용 |
|---|---|---|
| Q1 | 0 | 질문 은행 |
| 답변 n → (채점 + 다음 질문 or 꼬리질문) | 1 | **한 번의 호출**로 답변 채점·3인 반응·다음 질문 결정. 질문하는 면접관의 역할(임원/인사/실무)은 프롬프트의 역할 블록으로 전환 |
| 꼬리질문 | 턴당 1 | 면접 전체 최대 6개(현재 규칙 유지) |
| 상세 리포트 | 1 | 턴별 요약만 입력 |
| **합계** | **11~17회** | 본 질문 10턴 + 꼬리질문 0~6 + 리포트 1 |

## 3. 면접 1회당 원가 측정 방법 (구현 전 합의 필요)

1. **호출 단위 실측**: 모든 OpenRouter 요청에 `usage: { include: true }`를 넣어 응답의 `prompt_tokens`, `completion_tokens`, `cost`(달러)를 받는다. 응답에 비용이 없으면 모델 단가표(모델 API 캐시)로 계산한다.
2. **원장 기록**: 호출마다 D1 테이블 `llm_calls`에 `session_id, user_key, kind(question|turn|summary|report|ocr), model, tokens_in, tokens_out, cost_usd, ms, ok, fallback_reason`을 남긴다(질문·답변 본문은 저장하지 않음).
3. **세션 원가** = 해당 세션 `llm_calls.cost_usd` 합계. 재시도·실패 호출 비용도 포함.
4. **벤치마크 스크립트**(`scripts/cost-bench.ts`): 고정된 가상 지원자 3명 × 고정 답변 세트 × 모델 4종으로 무료·유료 면접을 자동 실행하고 모델별 평균·최대 원가, 지연 시간, 실패율, 품질 점수를 표로 출력한다.
5. **품질 점수**(항목 14): 같은 입력에 대해 ① 형식·언어 검사 통과율 ② 질문이 이력서·JD 근거를 인용했는지 ③ 직전 답변을 짚는 꼬리질문 비율 ④ 동문서답을 감점했는지(정답이 정해진 함정 답변 세트) ⑤ 고성능 모델을 기준으로 한 채점 일치도(점수 차이)를 자동 계산한다.

## 4. 구조 설계

### 4-1. 비용 통제 (항목 8~10)

- **DB**: Cloudflare D1(SQLite). 테이블 `users`(익명/계정), `sessions`(tier free|paid, 상태, 누적 비용), `llm_calls`(위 원장), `daily_budget`(날짜별 누적 비용), `entitlements`(결제 확인된 유료 이용권).
- **사용 제한**: 익명 기기 토큰(서명된 쿠키) + 계정 + IP 해시를 함께 센다. 서버에서 분당 요청 수 제한(키별 토큰 버킷, KV).
- **세션당 최대 비용**: 기본 무료 0.002달러, 유료 0.03달러. 넘으면 그 세션의 AI 호출 중단.
- **일일 전체 예산**: 기본 2달러/일. 넘으면 신규 AI 호출 중단.
- **긴급 중단 스위치**: 환경변수 `AI_KILL_SWITCH=on` 또는 KV 플래그 → 모든 AI 호출 즉시 중단, 화면에 "AI 면접이 일시 중지됨" 안내.

### 4-2. 정직한 대체 (항목 13)

- 한도·예산 초과 시 AI처럼 보이는 응답을 만들지 않는다. "오늘 무료 AI 면접 한도를 다 썼어요" 안내와 함께, **'데모 질문'이라고 표시된** 질문 은행 질문으로만 연습할 수 있게 한다.
- 지금처럼 규칙 기반 채점을 AI 채점과 같은 모양으로 보여주는 부분은 "AI 채점 아님" 표시를 유지·강화하거나, 무료 단계에서는 제거한다.

### 4-3. 결제 (항목 11)

- 유료 면접 시작 API는 서버에서 `entitlements`에 확인된 결제가 있어야만 열린다. 브라우저 값은 믿지 않는다.
- 결제 대행사 웹훅(서명 검증)으로만 `entitlements`를 만든다. 가격은 아직 미정(PRODUCT.md).

### 4-4. 키 관리 (항목 12)

- 이미 서버 전용. 빌드 산출물에 키 문자열이 없는지 검사하는 테스트를 CI에 추가한다.

## 5. 면접관 캐릭터·디자인 개편

### 5-1. 캐릭터 (첨부 1: 면접관 캐릭터 시트)

- 3인: **김도윤**(임원, 경영/전략, 다크 네이비 수트·안경·회색 머리), **이서연**(인사, 베이지 블레이저·묶은 머리), **박준호**(실무, 셔츠·사원증·노트북).
- 표정 6종: 기본, 미소, 진지, 의심, 끄덕임, 메모 중(세 캐릭터 공통 체계).
- 모션: 눈 깜빡임(2프레임, 3~6초 간격), 고개 끄덕임(6~8°, 내려갈·올라올 때 각 200~300ms), 입 모양 3단계(닫힘→약간 열림→열림, 0.2~0.4초 전환), 메모(시선 20~30° 하향, 1~2초 간격), 호흡(1~2px), 집중 시 눈썹 2~4° 상승.
- 구현안: 3D 절차 생성 아바타를 **2D 일러스트 레이어 방식**(몸·얼굴·눈·입·눈썹·손 레이어)으로 교체하고, 위 수치를 그대로 애니메이션 규칙으로 옮긴다. 기존 3D는 설정에서 끄는 대신 제거한다.

### 5-2. 디자인 시스템 (첨부 2: 랜딩 시안)

- 지금의 '면접 평가표'(잉크·빨간 펜) 방향을 **전면 교체**: 흰 바탕 + 라벤더 배경 장식, 주색 보라 `#6B46C1`, 네이비 `#1B1F2E`, 베이지 `#F6F2EA`, 그레이 `#E5E7EB`, 둥근 카드·버튼, 부드러운 그림자, 그라데이션 강조선.
- 랜딩 첫 화면: 좌측 문구 + "무료로 면접 시작하기"/"샘플 리포트 보기", 우측 면접실 화면(3인 캐릭터 + 질문 자막 + 면접 평가표 카드: 항목별 막대, 종합 점수, 종합 의견) + 하단 기능 3개 띠.
- 이전 디자인 규칙(그림자·그라데이션 금지, 손글씨 폰트 등)은 폐기하고 `DESIGN.md`를 이 시안 기준으로 다시 쓴다.

## 6. 결정이 필요한 사항

1. **결제 대행사**: 토스페이먼츠 / 포트원 / Stripe / 1단계는 결제 없이 관리자 발급 이용권 코드 중 무엇으로 갈지. 가격도 함께 정해야 유료 기능을 열 수 있습니다.
2. **계정**: 유료 이용권을 묶을 단위. 익명 기기 토큰만 / 이메일 로그인(매직 링크) / 소셜 로그인.
3. **캐릭터 에셋 원본**: 첨부 시트는 표정 셀이 약 170px이라 면접실 큰 화면에 쓰기엔 흐립니다. ① 시트를 만든 도구로 캐릭터별 고해상도 레이어 PNG(표정 6종 × 3명, 배경 투명)를 받아 쓰는 안(추천), ② 시트를 잘라 임시로 쓰는 안, ③ 비슷한 느낌으로 직접 그린 SVG 안.
4. **면접관 커스터마이즈**: 지금은 직무·직급·성별·성격을 사용자가 고를 수 있습니다. 시트의 고정 3인으로 바꾸면 이 기능이 줄어듭니다. 성격(온화/깐깐/압박)만 남기고 외형은 3인 고정으로 할지.
5. **예산 기본값**: 세션당 최대 비용(무료 0.002달러/유료 0.03달러)과 일일 전체 예산(2달러)이 적절한지.

## 7. 구현 순서(승인 후)

1. 원가 측정 계측(D1 원장, `usage` 수집) + 벤치마크 스크립트 → 현재 구조 실측
2. 질문 은행 + 턴당 1회 호출 엔진(무료 3문항/유료 11문항) + 요약 컨텍스트
3. 사용 제한·예산·긴급 중단·정직한 대체
4. 결제 확인 게이트(결정 1·2 이후)
5. 캐릭터 2D 레이어 아바타 + 디자인 시스템·랜딩 전면 교체(결정 3·4 이후)
6. 벤치마크 재측정 후 2-3 표를 실측값으로 갱신, 테스트·e2e·배포

## 8. 구현 결과와 실측 (2026-11-03)

### 바뀐 구조
- 면접 시작 시 AI 질문 생성 3회 → **0회**(질문 은행). 첫 질문은 항상 질문 은행의 자기소개.
- 답변마다 **AI 1회**: 채점 + 면접관 3명 반응 + 다음 질문 맞춤 재작성(다음 질문자의 직무·직급·성격을 프롬프트로 지정).
- 매 턴 전달: 현재 문답, 앞선 답변 요약 4개, 관련 이력서 문단 3개(500자), 채용공고 핵심 줄(700자), 다음 질문 초안. 대화 전체는 보내지 않음.
- 출력 상한: 턴 1,800 / 상세 리포트 2,000 / 요약 평가 900 / 이미지 읽기 2,500 토큰.
- 면접 길이: 빠른 면접(3문항, 요약 평가 1회) · 실전 면접(11문항, 상세 리포트). 둘 다 무료.
- 결제 대신 무료 + 후원(카카오페이·Fairy). 면접 횟수 제한(기기·IP·전체)은 삭제.

### 비용 통제
- 모든 호출의 토큰·실비용을 OpenRouter `usage`로 받아 KV 원장에 기록: 세션별, 날짜별(호출 종류·모델별), 익명 기기별.
- 예산: 빠른 면접 세션 $0.002, 실전 면접 세션 $0.03, 하루 전체 $2. 세션 내 호출 최소 간격 2초.
- 긴급 중단: `AI_KILL_SWITCH=on` 또는 `POST /api/usage {"paused":true}`(ADMIN_TOKEN 필요, 재배포 없이). `GET /api/usage`로 오늘 원장 확인.
- 거절되면 AI처럼 꾸미지 않음: 면접실에 "AI가 쉬는 중/오늘 AI 예산 소진" 안내 후 기본 질문 + 간이 채점(표시)으로 진행.

### 결론
- 기본 체인 유지: 무료 모델 → qwen(가장 저렴) → deepseek(빠르고 안정적). 실전 면접 1회 실비용은 약 0~21원.
- 고성능 모델(gemini·Sonnet)은 품질 차이가 크지 않은데 비용이 25~100배라 기본 체인에 넣지 않음.
- 무료 모델 하루 50회 한도는 계정에 10달러 이상 충전하면 1,000회로 늘어남(유료 대체 호출 비용도 그만큼 감소).
